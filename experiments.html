实验 1 · 最速降线赛道（Brachistochrone）

力学能量守恒变分思想惊艳指数 ★★★★★

一句话现象

三颗小球从同一起点同时释放、滑到同一终点：走"直线"的不是最快的，走一段"摆线"的反而第一个到——直觉被击碎的瞬间最震撼。

涉及知识

  • 机械能守恒：任意高度处速度只与下降高度有关，v = 根号(2*g*h)。
  • 最速降线（速降线）是一条摆线，不是直线，也不是圆弧——这是历史上著名的"伯努利挑战"（1696）。
  • 变分思想（泛函取极值）的直观启蒙：要让总时间最短，需在"路程"和"加速快慢"之间权衡。

实验原理

下滑总时间是沿轨道的积分：

T = ∫ ds / v ，其中 v = 根号(2*g*y)   （y 为已下降的竖直高度）

直线最短，但前段速度小，"省路程却不够快"；
摆线先陡后缓，前段迅速把重力势能换成速度，"先提速再赶路"，总时间最短。

摆线（滚动圆半径 r，参数 θ）的参数方程：
    x = r*(θ - sinθ)
    y = r*(1 - cosθ)
惊人结论之一（等时性）：在摆线上任意点释放，到达最低点用时相同，
    T_最低点 = π * 根号(r / g)

材料清单

材料规格/数量用途
透明亚克力板 / PVC 发泡板5mm 厚，约 60×40cm ×1切槽做轨道底板
柔性轨道槽（U 型铝槽或半圆 PVC 线槽）3 条，每条 ≥80cm嵌出三种曲线
钢珠 / 玻璃珠直径 12–16mm ×3（同规格）滑块，必须完全相同
电磁释放门 / 同步挡板1 套保证三球"同时"释放
坐标纸 / 打印的摆线模板A2 ×1照模板弯曲轨道

设备

  • 手机高速摄像（120/240fps 慢动作）或双光电门 + 计时器；
  • 热熔胶枪、美工刀、卷尺、量角器。

制作方法与步骤

  1. 用参数方程 x=r(θ-sinθ), y=r(1-cosθ) 取 r≈12cm，θ 从 0 到 π，打印摆线模板；直线、圆弧用直尺/圆规画。
  2. 把三条轨道槽按模板固定在底板上，三条起点等高、终点同点。
  3. 装同步释放门：一根可同时抬起的横杆挡住三球，抬杆即同时释放。
  4. 调水平，消除底板倾斜误差；轨道内壁打磨光滑减小摩擦。
  5. 慢动作录像，逐帧读出到达终点时刻。

数据分析

记录三条轨道到达终点用时 t_直、t_弧、t_摆，重复 5 次取平均。
预期：t_摆 < t_弧 < t_直。

进阶定量：摆线落到最低点理论时间 T = π*根号(r/g)。
取 r=0.12m，g=9.8： T = 3.1416 * 根号(0.12/9.8) ≈ 0.347 s
把实测最低点时间与理论值比对，误差主要来自摩擦与滚动（钢珠滚动惯量使等效 g 略减小）。
滚动修正：实心球纯滚动时 v = 根号(10*g*h/7)，相当于把 g 换成 (5/7)g。

注意事项

  • 三球必须同材质、同直径、同质量，否则比较不公平。
  • 同步释放是成败关键，释放门要无初速度、无侧向推力。
  • 轨道接缝要平滑，缝隙会让球"跳起"产生大误差。

难度分析

制作难度 ★★★☆☆（曲线放样与同步释放是难点）；理解难度 ★★★☆☆（现象易懂，变分原理只需定性）。单课时可演示，做精需半天。

合理性分析

把一道 300 多年的经典数学物理难题变成肉眼可见的"赛跑"，认知冲突强、可证伪、可定量，且材料便宜安全。等时性还能延伸到"摆线摆钟"，串联到实验 3 的振动主题。

实验 2 · 动量放大"火箭球"发射器

力学动量守恒弹性碰撞竞赛题改造惊艳指数 ★★★★★

一句话现象

大球上叠小球一起落地，小球被"弹射"到远高于落点的高度——两球理论上可到 9 倍落差，三球叠放更夸张。这是经典竞赛题"叠球弹跳"的实体版。

涉及知识

  • 一维弹性碰撞的速度交换/放大；动量守恒与动能守恒联立。
  • 参考系变换（站在大球上看小球）的巧妙思想。

实验原理

设大球质量 M、小球 m，从高 h 同时下落，落地前速度都为
    v = 根号(2*g*h)   （方向向下）

大球先触地弹回，速度变为 v（向上）；此刻小球仍以 v 向下。
两者相对速度为 2v。对 M >> m 的理想极限，弹性碰撞后
小球速度 ≈ 3v（向上）。

一般弹性碰撞公式（碰前大球 +v、小球 -v）：
    v_小' = ( (m - M)/(m + M) )*(-v) + ( 2M/(m + M) )*(v)
          = ( (3M - m)/(M + m) ) * v
当 M >> m： v_小' → 3v

弹起高度（忽略空气阻力）：
    H = v_小'^2 / (2*g) = 9 * h   （理想极限）
三球叠放（质量自下而上递减）理论上更高，但实际受碰撞非理想、空气阻力限制。

材料清单

材料规格/数量用途
篮球 / 大弹力球1（最重，放最下）主反弹体 M
网球1（中）中间层
乒乓球 / 小弹力球1（最轻，放最上）被发射体 m
对中导杆（可选）细木签 + 中心打孔保证同轴叠放
高度标尺≥3m 卷尺贴墙读弹起高度

设备

  • 手机慢动作摄像、靠墙刻度尺；空旷高顶场地（室外或体育馆）。

制作方法与步骤

  1. 先两球版：网球轻放篮球正上方，对中。
  2. 站姿固定，从约 1m 高同时释放（手撤离要干脆，避免给上球初速）。
  3. 慢动作录下弹起高度，重复多次。
  4. 进阶三球版：篮球-网球-乒乓球同轴叠放（可用导杆对中），发射方向务必朝上无人区。

数据分析

测落差 h 与弹起高度 H，算放大比 H/h。
两球理论极限 H/h = 9；实际常见 3～5（因质量比有限、碰撞非完全弹性、空气阻力）。

由弹起高度反推小球出射速度：v_小' = 根号(2*g*H)
用速度比 v_小'/v 检验是否接近理论 (3M - m)/(M + m)。
做"放大比 vs 质量比"曲线，验证质量比越大、放大越强的趋势。

注意事项

  • 发射方向绝对避开人、灯具、窗户；戴护目镜。
  • 三球叠放极易飞偏，先在空旷室外练习。
  • 释放瞬间双手同时撤离，避免人为加速上球造成假数据。

难度分析

制作难度 ★☆☆☆☆；理解难度 ★★★☆☆（参考系变换是亮点）。十分钟即可出震撼效果。

合理性分析

用三只球还原"叠球弹跳"竞赛题，把抽象的"速度放大 3 倍、高度放大 9 倍"变成看得见的飞跃；成本极低、可重复、可定量，是讲弹性碰撞与参考系的王牌演示。

实验 3 · 耦合摆与共振演示墙（Barton 摆）

力学简谐振动受迫振动共振惊艳指数 ★★★★☆

一句话现象

一排长度不同的摆挂在同一根绳上，只摇动其中一个"驱动摆"，结果只有和它一样长的那个摆越摆越大，其余的几乎不动——共振被"挑"了出来。

涉及知识

  • 单摆固有周期 T = 2*π*根号(L/g)，固有频率 f = 1/T。
  • 受迫振动的稳态振幅在驱动频率≈固有频率时最大（共振），并伴随相位变化。

实验原理

单摆固有频率只由摆长决定：
    f0 = (1/(2π)) * 根号(g / L)

横挂的支撑绳把驱动摆的振动以"驱动频率 = 驱动摆固有频率"传给所有摆。
某个摆的固有频率越接近这个驱动频率，其稳态振幅越大：
    A(f) ∝ 1 / 根号( (f0^2 - f^2)^2 + (γ f)^2 )     （γ 为阻尼系数）
当 f ≈ f0 时 A 最大 —— 这就是共振。
等长摆 = 同 f0 = 被"选中"剧烈摆动。

材料清单

材料规格/数量用途
支撑横绳（较松软的棉线）1 根 ~1m耦合各摆、传递驱动
立柱/门框两点2 处张紧横绳
细线 + 螺帽/橡皮泥球6–8 组，长度递变不同固有频率的摆
稍重的驱动摆1（质量略大）提供稳定驱动

设备

  • 秒表/手机、卷尺、量角器（测振幅角）。

制作方法与步骤

  1. 把棉横绳两端固定张紧（略松，便于传递振动）。
  2. 挂 6–8 个摆，摆长从短到长排列，其中一个与驱动摆等长。
  3. 驱动摆质量略大、摆球略重，使驱动持续稳定。
  4. 仅拉开驱动摆释放，观察哪个摆逐渐"长大"。

数据分析

测每个摆的摆长 L，算固有频率 f0 = (1/2π)*根号(g/L)。
稳态后量各摆最大摆幅角 θ_max。
以横轴 f0、纵轴 θ_max 作图 —— 得到一条在驱动频率处出现尖峰的"共振曲线"。
峰位应对应等长摆，验证 f≈f0 时振幅最大。
还可观察相位：远低于共振时同相，远高于时反相，共振处约差 90°。

注意事项

  • 横绳太紧则耦合弱、现象不明显；偏松一点效果更好。
  • 初始只给驱动摆能量，其余摆要静止。
  • 风、桌面晃动会干扰，选无风环境。

难度分析

制作难度 ★★☆☆☆；理解难度 ★★★☆☆。半小时搭好，现象稳定。

合理性分析

把"共振"从公式变成可视化的"选择性放大"，直接对应桥梁/秋千/乐器等真实场景；零成本、可定量出共振曲线，是受迫振动一章的最佳实物。

实验 4 · 角动量守恒转盘

转动力学角动量守恒转动惯量惊艳指数 ★★★★☆

一句话现象

坐在可自由旋转的转椅上，两手伸开拿哑铃慢慢转，突然收回双臂——转速猛地加快，像花样滑冰收臂加速一样。手持转动的自行车轮还能让人原地转向。

涉及知识

  • 角动量 L = I*ω；无外力矩时 L 守恒。
  • 转动惯量 I 随质量分布变化：质量越靠轴，I 越小。

实验原理

无外力矩时角动量守恒：
    I1 * ω1 = I2 * ω2

收臂使转动惯量从 I1 减小到 I2 (I2 < I1)，故角速度增大：
    ω2 = (I1 / I2) * ω1

转动动能并不守恒（人做了功）：
    Ek = (1/2)*I*ω^2 = L^2 / (2*I)
I 减小 → Ek 增大，多出的能量来自手臂收回时肌肉做的功。

自行车轮陀螺：竖直方向角动量守恒，翻转轮子时人体反向旋转以抵消。

材料清单

材料规格/数量用途
可自由旋转的转椅 / 转盘平台1（轴承顺滑）近似无摩擦力矩
哑铃 / 装水的瓶子2（等重）改变质量分布
自行车轮 + 手柄1（进阶演示）陀螺/进动

设备

  • 手机慢动作或手机陀螺仪 App（读角速度）、秒表（数圈计时）。

制作方法与步骤

  1. 人坐稳转椅，双脚离地，双手持哑铃水平伸开。
  2. 助手轻推使其缓慢匀速旋转，记初始转速。
  3. 受试者把哑铃快速收到胸前，观察并记录转速变化。
  4. 进阶：手持高速旋转的自行车轮，尝试翻转轮轴，人体会反向转动。

数据分析

用"10 圈所需时间"测前后角速度 ω1、ω2。
估算 I1、I2（人体+手臂+哑铃，按质点到轴距离 r 估 I≈Σ m r^2）。
检验 I1*ω1 ≈ I2*ω2（守恒）。
比较 Ek1 = (1/2)I1 ω1^2 与 Ek2 = (1/2)I2 ω2^2，
说明 Ek2 > Ek1，差值即收臂时肌肉做的功。

注意事项

  • 系好支撑、旁边有人保护，防止转太快眩晕摔落。
  • 哑铃别脱手；自行车轮转速不要过高。
  • 转椅轴承越顺滑、误差越小。

难度分析

制作难度 ★☆☆☆☆；理解难度 ★★★☆☆。几乎零制作，效果立竿见影。

合理性分析

用身体亲历"角动量守恒"，比任何动画都深刻；还能引出"动能不守恒、能量从哪来"的好问题，串到能量守恒主题。安全可控、可定量。

实验 5 · 铜管中"缓降"的磁铁（楞次定律涡流）

电磁学电磁感应楞次定律涡电流惊艳指数 ★★★★★

一句话现象

把一块强磁铁丢进竖直铜管，它不是"啪"地落下，而是像在糖浆里一样慢悠悠地飘下来；同样大小的非磁铁块则瞬间坠落。神奇又安静。

涉及知识

  • 法拉第电磁感应定律：变化磁通产生感应电动势。
  • 楞次定律：感应电流的效果总是阻碍引起它的变化（电磁阻尼）。
  • 涡电流、终端速度（阻力与速度成正比）。

实验原理

磁铁下落时穿过铜管，管壁各横截面处磁通在变化：
    感应电动势 ε = - dΦ/dt
铜是良导体，管壁中形成闭合"涡电流"，按楞次定律其磁场阻碍磁铁运动，
表现为一个与速度成正比的电磁阻力：
    F_阻 ≈ k * v      （k 取决于磁铁强度、管壁电导率与壁厚）

当电磁阻力增大到与重力平衡，磁铁做匀速下落（终端速度）：
    m*g = k * v_终     →     v_终 = m*g / k

铜管壁越厚、磁铁越强、管电阻率越低，k 越大，下落越慢。
塑料管不导电，无涡流，磁铁自由落体。

材料清单

材料规格/数量用途
厚壁铜管（或铝管）内径略大于磁铁，长 ≥50cm产生涡流
钕磁铁圆柱/圆片，能在管内顺滑下落 ×1–2下落磁体
同尺寸 PVC/塑料管1（对照）无涡流对比
同体积非磁铁块（铁/铅除外的小块）1（对照）排除"是不是因为重"

设备

  • 秒表/手机慢动作；上下两个光电门 + 计时器（测终端速度更准）。

制作方法与步骤

  1. 竖直夹持铜管，下端留软垫接磁铁。
  2. 磁铁从管口轻放（无初速）下落，秒表计时；重复多次。
  3. 换塑料管、换非磁性块做对照。
  4. 进阶：在管不同高度装两个光电门，直接测某段平均速度判断是否已达终端速度。

数据分析

比较铜管 vs 塑料管下落时间（铜管可达数秒，塑料管零点几秒）。
测终端速度 v_终 = 管长 / 下落时间（若全程近似匀速）。
改变变量验证模型：
  - 叠加 2 块磁铁（磁矩增大）→ 下落更慢；
  - 换更厚壁/更长铜管 → 更慢；
  - 铝管比铜管略快（电导率低，k 较小）。
由 m*g = k*v_终 反求阻尼系数 k = m*g / v_终。

注意事项

  • 钕磁铁极强：远离手机、银行卡、机械表、起搏器；小心夹手。
  • 磁铁勿吞、勿给低龄者；两块磁铁相吸会猛烈撞击碎裂飞溅。
  • 管口加软垫，防磁铁落地碎裂。

难度分析

制作难度 ★☆☆☆☆；理解难度 ★★★☆☆。买到铜管和钕磁铁即可，5 分钟见效。

合理性分析

这是楞次定律最震撼、最"反常识"的演示，且天然带对照实验设计（铜管 vs 塑料管、磁性 vs 非磁性），非常适合训练控制变量法。与磁悬浮、电磁制动、感应炉同源。

实验 6 · 30 秒单极电机（最简电动机）

电磁学安培力洛伦兹力极简创客惊艳指数 ★★★★☆

一句话现象

一节电池、一颗钕磁铁、一根铜丝——铜丝突然自己飞快地转起来，没有齿轮没有电路板。号称"世界上最简单的电动机"。

涉及知识

  • 通电导体在磁场中受安培力 F = B*I*L；微观为洛伦兹力 F = q*v×B。
  • 力的方向由左手定则/F = I L×B 决定，决定了旋转方向。

实验原理

电池正极—铜丝—磁铁—电池负极构成回路，电流 I 流过铜丝。
磁铁提供磁场 B（在铜丝处既有竖直分量也有径向分量）。
电流的径向分量与磁场的轴向分量叉乘，产生沿切线方向的安培力：
    F = I * L × B
该切向力对转轴产生力矩，使铜丝绕电池轴线持续旋转。
电流方向或磁极方向反一个，旋转方向反一次（反两个则不变）。

注意：单极电机不需要换向器，因为受力方向始终切向、不随转动反向。

材料清单

材料规格/数量用途
AA 干电池1.5V ×1电源
钕磁铁圆片，直径≈电池底径 ×1提供磁场 + 接触负极
裸铜丝较硬，可弯成对称形状 ×1转子（载流导体）

设备

  • 尖嘴钳（弯铜丝）；无需其它仪器。

制作方法与步骤

  1. 磁铁吸在电池负极（平底）上。
  2. 把铜丝弯成"心形/螺旋形"，顶端做一个小凹点，扣在电池正极凸点上（作为可转动的支点，几乎无摩擦）。
  3. 调整铜丝两侧下端，让它们轻轻擦到磁铁边缘形成回路。
  4. 松手——铜丝开始旋转。转不动就微调铜丝接触点和重心对称性。

数据分析

定性为主：
  - 把磁铁翻面（N/S 互换）→ 转向相反；
  - 电池正负方向不变而磁极反 → 反向，验证 F = I L×B 的方向规律。
半定量：用手机慢动作数转速（转/秒），比较不同磁铁强度、不同铜丝长度对转速的影响。
注意电流较大（近似短路），电池会发热、耗电快，单次演示别超过 1～2 分钟。

注意事项

  • 这是近似短路：电池和铜丝会发热，演示后及时拆开，别长时间运行。
  • 钕磁铁注意夹手与吞食风险。
  • 铜丝转速快，注意别让飞转的端部扫到眼睛。

难度分析

制作难度 ★☆☆☆☆；理解难度 ★★☆☆☆。30 秒能做出来，调平衡需要一点耐心。

合理性分析

把"安培力使电机转动"这一核心原理剥到最简，没有任何多余结构干扰理解；零成本、人人可做，是电磁学动手第一课，可自然过渡到换向器、直流电机的讨论。

实验 7 · 手摇发电机（法拉第电磁感应定律）

电磁学电磁感应法拉第定律能量转化惊艳指数 ★★★★☆

一句话现象

摇动手柄让磁铁在线圈里飞速进出/旋转，LED 灯随之点亮，摇得越快越亮——机械能"无接触"地变成了电能。和实验 6（电变机械）正好是一对逆过程。

涉及知识

  • 法拉第电磁感应定律：ε = - N * dΦ/dt。
  • 动生电动势、能量转化（动能→电能→光/热能）。

实验原理

线圈匝数 N，磁通 Φ = B*A*cosθ。磁铁相对线圈运动使 Φ 变化，产生电动势：
    ε = - N * dΦ/dt

旋转式（磁铁匀速转，角速度 ω）：
    ε(t) = N*B*A*ω*sin(ω t)        峰值 ε0 = N*B*A*ω
所以：匝数 N 越多、磁场 B 越强、转得越快 ω 越大 → 电压越高、灯越亮。

能量角度：手的机械功率 → 电功率 P = ε^2 / R（点亮 LED/电阻发热发光）。
摇得快时手感更"沉"——因为输出电功率大，需要更多机械功（楞次定律的反作用）。

材料清单

材料规格/数量用途
漆包线（带绝缘漆的铜线）0.3–0.5mm，绕 200–500 匝感应线圈
钕磁铁1–2 块旋转/往复磁源
线圈骨架（纸管/塑料管）1绕线
LED（或小灯珠）2 只反并联更好显示发电（交流双向）
手柄 / 小曲柄 + 转轴1 套驱动磁铁

设备

  • 万用表（测交流电压/感应电压）、示波器（可选，看正弦波形最直观）。

制作方法与步骤

  1. 在纸管上密绕 200–500 匝漆包线，两端刮去绝缘漆。
  2. 线圈两端接 LED（两只 LED 反向并联，正反向都亮，证明是交流）。
  3. 把磁铁固定到可转动的轴/曲柄上，置于线圈端口附近。
  4. 摇动手柄，观察 LED 随转速变亮；接万用表/示波器看电压。

数据分析

变量探究（控制变量）：
  - 转速 ω ↑ → 感应电压峰值 ↑（理论 ε0 = N B A ω，应近似线性）；
  - 匝数 N ↑ → 电压 ↑（成正比）；
  - 磁铁更强 / 更近 → B、Φ 变化更大 → 电压 ↑。
用万用表读不同转速下电压，作 "电压 - 转速" 图，验证线性关系。
示波器可直接显示 ε(t) 近似正弦，频率 = 磁铁转动频率。

注意事项

  • 全部低压自制，严禁接市电 220V。
  • 漆包线端头务必刮净绝缘漆才能导电。
  • LED 有极性，建议两只反并联以适应交流。

难度分析

制作难度 ★★★☆☆（绕线和做转轴稍费时）；理解难度 ★★★☆☆。半天可完成可定量版本。

合理性分析

与实验 6 构成"电动机↔发电机"互逆对照，深化能量转化与法拉第定律；可定量做出"电压-转速""电压-匝数"关系，安全、可扩展（手机充电、点灯），工程感强。

实验 8 · 瓶中云（绝热膨胀造云）

热学绝热过程理想气体相变惊艳指数 ★★★★☆

一句话现象

往瓶里打点气、再"啪"地一下放气，瓶中瞬间出现一团白云；再加压，云又消失。亲手在桌上造出一朵云。

涉及知识

  • 气体绝热膨胀做功使内能减小、温度下降。
  • 露点、凝结核与相变（水汽→小水滴）。
  • 理想气体状态方程与绝热过程关系。

实验原理

瓶内先加压，气体被压缩、温度略升；突然泄压时气体迅速膨胀，
来不及与外界换热（近似绝热），气体对外做功、内能下降、温度骤降：
    绝热过程：P * V^γ = 常数 ；  T * V^(γ-1) = 常数   （γ=Cp/Cv，空气≈1.4）

温度降到露点以下，空气中的水汽达到过饱和。
此时若有"凝结核"（火柴烟尘微粒），水汽就凝结成大量小水滴 → 看见白云。
重新加压：温度回升、未饱和，水滴蒸发 → 云消失。
关键三要素：水汽 + 降温（绝热膨胀）+ 凝结核。

材料清单

材料规格/数量用途
透明塑料瓶（耐压，如汽水瓶）500mL–1.5L ×1反应容器（勿用玻璃）
带气阀的瓶塞 / 打气筒1 套（如打气球的气针塞）加压与泄压
少量水润湿瓶壁即可提供水汽
火柴1 根（点燃后投入产生烟尘）凝结核

替代加压方案：把瓶口套在打气筒上加压，或挤压瓶身（效果较弱）。最稳妥的是带单向气阀的加压瓶塞。

设备

  • 手机摄像；可选数字温度探头（伸入瓶内记录温降）。

制作方法与步骤

  1. 瓶里加少量水，摇晃润湿，倒掉多余水（留水汽）。
  2. 点一根火柴，吹灭后让一缕烟进入瓶中作凝结核，迅速塞紧带气阀的塞子。
  3. 用打气筒加压几下（瓶子明显变硬）。
  4. 猛地拔塞/开阀泄压——瓶内立刻出现白云。再加压，云消失。可反复。

数据分析

对照实验（验证三要素）：
  - 无烟尘（无凝结核）：泄压后云很淡甚至不成云；
  - 无水汽（干燥瓶）：不成云；
  - 不泄压（无绝热降温）：不成云。
半定量：用温度探头记录泄压瞬间瓶内温度下降 ΔT（常见可降几摄氏度）。
联系真实大气：上升气流绝热膨胀冷却 → 成云致雨，与本实验同理。

注意事项

  • 务必用塑料瓶并控制加压程度，切勿过压，防止瓶塞/瓶体爆开伤人；戴护目镜。
  • 火柴用火安全，吹灭确认无明火再投烟。
  • 泄压时瓶口不要对人。

难度分析

制作难度 ★★☆☆☆；理解难度 ★★★☆☆。十几分钟可成，调到稳定出云需多试几次。

合理性分析

把抽象的绝热过程和"云怎么形成"变成桌面奇观，天然适合做控制变量对照（水汽/凝结核/降温缺一不可），直接连通天气与气象，跨学科价值高、成本极低。

实验 9 · 人造天空与日落（瑞利散射）

光学散射光的颜色惊艳指数 ★★★★☆

一句话现象

一束白光穿过加了几滴牛奶的水：从侧面看，水是淡蓝色（像白天的天空）；从正对光源的出口看，光变成橙红色（像日落）。一缸水演出一整天的天色。

涉及知识

  • 瑞利散射：微粒对光的散射强度与波长四次方成反比。
  • 蓝光波长短被散射强（天空蓝）；透射光被滤掉蓝光、剩红光（朝霞/落日红）。

实验原理

当散射颗粒远小于波长时，散射强度：
    I_散射 ∝ 1 / λ^4

蓝光 (λ≈450nm) 比红光 (λ≈650nm) 波长短，散射强度比约：
    (650/450)^4 ≈ 4.3 倍
所以侧向散射出来的光偏蓝 → "天空是蓝的"。
而沿原方向透射的光被不断散射掉蓝色成分，越往后越偏红 →
"夕阳/落日是红的"（光在大气中经过的路径长，相当于水缸加长）。
牛奶中的微小脂肪/蛋白颗粒就是散射体，模拟大气分子/微粒。

材料清单

材料规格/数量用途
透明水槽 / 长方形玻璃缸 / 大号矿泉水瓶1（越长越好）盛散射介质
清水装满介质
牛奶 / 几滴洗洁精几滴起（逐滴加）散射颗粒
强白光手电（聚光好）1光源（模拟太阳）

设备

  • 手机相机（拍照后用取色器读 RGB 做定量）；暗室或遮光环境。

制作方法与步骤

  1. 水槽装满清水，关灯遮光。
  2. 手电从一端水平射入，先看纯水——几乎无色。
  3. 滴入几滴牛奶并搅匀，逐渐增加。侧面观察泛蓝，出口端观察偏黄→橙→红。
  4. 调整牛奶浓度和观察角度，找最明显的"蓝天/落日"对比。

数据分析

定量：在侧面与出口各拍一张照片，用取色工具读 RGB。
  - 侧向散射光：B 分量相对偏高（偏蓝）；
  - 透射出口光：R 分量相对偏高（偏红）。
改变水槽长度/牛奶浓度（等效大气厚度），观察出口颜色从黄→红的渐变，
对应"正午太阳偏白、日出日落偏红"（阳光斜射穿过更厚大气）。
可定性验证 1/λ^4：蓝色散射明显强于红色。

注意事项

  • 用普通白光手电，不要用激光笔对眼睛或他人。
  • 牛奶逐滴加，过浓会全白看不出颜色分离。
  • 玻璃缸小心磕碰破裂，优先用塑料容器更安全。

难度分析

制作难度 ★☆☆☆☆；理解难度 ★★★☆☆。十分钟出效果，调浓度找最佳对比。

合理性分析

一次性解释"天为什么蓝、晚霞为什么红"两个生活大问题，视觉冲击强、成本几乎为零，能定量（RGB 取色）也能定性，是光学散射的明星实验。

实验 10 · 跨学科多米诺连锁装置（鲁布·戈德堡机械）

综合集成力学电磁热学光学能量链惊艳指数 ★★★★★

一句话现象

触发第一颗小球后，装置自动逐级触发：力学→电磁→光学→热学，最后"造出一朵云"或亮起终点灯。把前 9 个实验的核心串成一条会自己跑完的连锁反应链，是展评和汇报的压轴大戏。

涉及知识

  • 系统工程思想：时序、触发、容错、模块接口。

设计思路（一条建议链）

能量链（每一步触发下一步）：

   ↓ 撞击

材料清单（在前面模块基础上增加）

材料用途

设备

  • 万用表、电烙铁（或免焊面包板）、手机摄像（记录连锁全过程）、秒表。

制作方法与步骤（分模块、先单测后串联）

  1. 把每个子实验做成独立"模块盒"，各自能稳定工作（单测通过率 ≥ 9/10 再进入集成）。
  2. 设计统一接口：上一模块输出"机械碰撞 / 闭合开关 / 给电 / 给光"，作为下一模块触发输入。
  3. 逐段串联调试：先串前两段，跑通后再加一段，避免一次全连查错困难。
  4. 用"铜管缓降"作天然延时，给后级留出动作时间。
  5. 全链路彩排，记录失败点并加裕量（如加大撞击力、增加导引轨防跑偏）。
  6. 正式演示录像，配解说牌标注每一步的物理原理与能量形式。

数据分析

- 可靠性：统计 N 次触发的整链成功率，定位最易失败的环节并改进。
- 时序：用录像逐帧记录每一级触发的时刻，画"时间轴"，分析铜管延时是否足够。
- 能量流：标注每一步的能量形式（重力势能→动能→电能→光能→内能/相变），
  讨论每步的能量损耗（摩擦、电阻发热、散射损失），体会"能量守恒但品质下降"。

注意事项

  • 全部用低压电源，不接市电；继电器用于隔离与控制。
  • 激光改用普通强光手电更安全；若用激光须固定光路、严禁扫到人眼。
  • 钕磁铁、发射/弹跳类环节遵循各自实验的安全须知。
  • 集成调试耗时，预留充足时间与备用元件。

难度分析

制作难度 ★★★★★（系统集成与调试是最大挑战）；理解难度 ★★★★☆。适合作为项目周/社团长线作品，3–5 人团队 1–2 周。

合理性分析

把割裂的知识点缝合成一个有因果、有时序、会"讲故事"的系统，极大激发兴趣与成就感；天然训练工程思维、团队协作与排错能力，是整套方案的高潮与展评亮点。可按学情删减环节，弹性极大。
